## UI/UX Design Rules

Design interfaces that feel intentionally designed by a professional product designer,
not generated from a generic AI dashboard template.

Avoid:
- Excessive rounded cards
- Excessive use of gradients
- Purple/blue AI-style color palettes unless required by the brand
- Glassmorphism unless specifically requested
- Huge headings with excessive whitespace
- Every section being placed inside a card
- Repetitive card grids
- Generic "SaaS dashboard" layouts
- Unnecessary icons beside every label
- Excessive shadows
- Decorative elements that have no functional purpose
- Giant hero sections for ordinary application screens
- Generic stock illustrations
- Random badges/pills everywhere

Prefer:
- Strong visual hierarchy
- Purposeful whitespace
- Clear alignment and consistent spacing
- Subtle borders and restrained shadows
- A limited, intentional color palette
- Typography with clear hierarchy
- Dense but readable information where appropriate
- Tables when information is naturally tabular
- Realistic empty/loading/error states
- Contextual actions rather than decorative buttons
- Consistent interaction patterns
- Responsive layouts designed intentionally for each breakpoint

Before creating a page:
1. Identify the primary user task.
2. Identify the most important information.
3. Establish the visual hierarchy.
4. Choose the appropriate layout for the content.
5. Reuse existing project components where appropriate.
6. Do not introduce a new visual pattern when an existing one already works.

The interface should feel like a mature production product, not a UI concept or design showcase.
